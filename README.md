# Moe Kyaw Dashboard

A professional React dashboard for Android development projects, technical skills, career roadmap, and professional certificates.

The interface is designed for a modern Android senior developer portfolio and includes project tracking, skill mastery, career progression, and certificate presentation.

## Live Demo

- Website: https://your-domain.example
- GitHub: https://github.com/Dev-moe-kyawaung
- GitLab: https://gitlab.com/your-username

## Features

- Project progress dashboard.
- Task filtering by completion status.
- Task progress chart and status distribution chart.
- Android skill matrix.
- Competency radar chart.
- Technology stack badges.
- Career roadmap from Intern to Android Architect.
- Professional certificate page.
- Print and save certificate as PDF.
- Responsive layout for desktop, tablet, and mobile.
- GitHub Actions CI pipeline.
- GitLab CI/CD pipeline.
- Cloudflare Pages deployment.
- Vercel deployment.
- Netlify deployment.
- SPA route fallback support.

## Requirements

- Node.js 20 or later.
- npm 10 or later.
- Git.
- A GitHub or GitLab account for repository hosting.
- Optional: Cloudflare, Vercel, or Netlify account for deployment.

## Installation

Clone the repository:

```bash
git clone https://github.com/Dev-moe-kyawaung/moekyaw-dashboard.git
cd moekyaw-dashboard
```
## Install dependencies:
```
npm install
```
## Create the local environment file:
```
cp .env.example .env
```

## Start the development server:
```
cp .env.example .env
```
## open:
```
http://localhost:5173
```
